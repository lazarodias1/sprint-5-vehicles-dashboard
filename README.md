Vehicle Sales Dashboard

This project is an interactive web dashboard developed with Python and Streamlit as part of the TripleTen Data Analyst Bootcamp — Sprint 5.

Project Description

The application explores a dataset of used car advertisements in the United States, allowing users to visualise vehicle sales data.

Features

Histogram: Displays the distribution of vehicle mileage (odometer).

Scatter Plot: Shows the relationship between vehicle mileage and price.

Interactive Buttons: Allow users to generate each chart.

Technologies Used

Python

Pandas

Plotly Express

Streamlit

How to Run Locally

Install the required packages:

pip install -r requirements.txt

Start the application:

streamlit run app.py
